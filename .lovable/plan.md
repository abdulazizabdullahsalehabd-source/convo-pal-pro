
# خطة بناء تطبيق "صديق المحادثة"

تطبيق ويب متجاوب (يعمل كتطبيق جوال PWA) مبني على TanStack Start مع Lovable Cloud للـ Auth وقاعدة البيانات، و Lovable AI Gateway للذكاء الاصطناعي والصوت.

## ملاحظات مهمة قبل البدء

1. **"تطبيق جوال" حقيقي (APK/iOS):** منصة Lovable تبني تطبيقات ويب فقط. سأبني تطبيق ويب متجاوب بتصميم موبايل بالكامل + PWA (قابل للتثبيت على الشاشة الرئيسية للهاتف ويعمل كتطبيق). لا يمكن إنتاج ملف APK أصلي مباشرة.
2. **ملف ZIP:** لا أستطيع إرسال ملف مضغوط عبر الشات، لكن يمكنك تنزيل المشروع كامل من زر **GitHub → Export** أو **Download** في واجهة Lovable بعد الانتهاء.
3. **"مجاني وغير محدود إلى الأبد":** Lovable AI Gateway يوفر رصيداً شهرياً مجانياً سخياً (Gemini مجاناً حتى 6 أكتوبر ثم بأسعار منخفضة جداً). لا توجد خدمة LLM/TTS احترافية مجانية 100% وغير محدودة فعلياً — أي مزود سيضع حداً ما. سأستخدم أرخص وأكفأ النماذج (Gemini Flash Lite) لتقليل الاستهلاك لأدنى حد، وسأستخدم Web Speech API المدمج في المتصفح للـ STT و TTS كخيار أول (مجاني 100% وغير محدود)، مع اللجوء إلى Gemini فقط لتوليد الرد الذكي والتصحيح.

## البنية التقنية

- **Frontend:** TanStack Start + React + Tailwind (تصميم موبايل أولاً)
- **Auth:** Lovable Cloud → Google Sign-In
- **DB:** Lovable Cloud (Supabase) — جداول `conversations` و `messages`
- **STT (تحويل الصوت لنص):** Web Speech API في المتصفح (مجاني وغير محدود)
- **LLM (الرد + كشف الأخطاء):** `google/gemini-3.6-flash` عبر Lovable AI Gateway مع مخرجات منظمة JSON
- **TTS (نص إلى صوت):** Web Speech API `SpeechSynthesis` في المتصفح (مجاني وغير محدود، يدعم العربية والإنجليزية)

## هيكل الشاشات

```
/                      → صفحة هبوط + زر تسجيل دخول Google
/auth                  → معالجة OAuth
/conversations         → قائمة المحادثات المحفوظة + زر "محادثة جديدة"
/conversations/$id     → شاشة الدردشة (رسائل + ميكروفون + بطاقات تصحيح)
```

## قاعدة البيانات

```sql
conversations (id, user_id, title, created_at, updated_at)
messages (id, conversation_id, role, content, language, correction_jsonb, created_at)
```
مع RLS: كل مستخدم يرى محادثاته فقط.

## منطق الذكاء الاصطناعي

Server function واحدة `chat` تستقبل: تاريخ الرسائل + النص الجديد + اللغة المكتشفة، وترجع JSON:
```json
{
  "reply": "...",
  "reply_language": "en" | "ar",
  "correction": { "wrong": "...", "correct": "...", "hint": "..." } | null
}
```

**System prompt** يشمل:
- الرد بنفس لغة المستخدم (إنجليزية أو عربية فقط)
- إذا كتب المستخدم بالعربية: الرد بالعربية + إضافة رسالة تشجيعية في نهاية كل رد لاستخدام الإنجليزية
- كشف الأخطاء النحوية للإنجليزية فقط ووضعها في `correction`
- معلومات المطور (عبدالعزيز عبدالله صالح عَبَد، تريم، حضرموت، اليمن، ثانوية سيئون النموذجية...) بالعربية والإنجليزية — يجيب عليها إذا سُئل عن الصانع/المطور/المصمم

## واجهة الدردشة (Mobile-first)

- شريط علوي: اسم المحادثة + زر رجوع + قائمة المحادثات
- منطقة رسائل قابلة للتمرير:
  - فقاعة المستخدم (يمين، لون Primary)
  - فقاعة الذكاء الاصطناعي (يسار، رمادي فاتح) + زر تشغيل الصوت 🔊
  - **بطاقة التصحيح** أسفل رد الذكاء (حدود برتقالية/صفراء مميزة): "ما قلته / الأصح / السبب"
- شريط سفلي ثابت: زر ميكروفون كبير دائري في المنتصف
  - ضغط مطول = تسجيل + موجة صوتية متحركة (Animation)
  - عند الإفلات: يظهر "يستمع..." ثم "يفكر..." (typing indicator)
- حقل نص اختياري للكتابة بدل التسجيل

## دعم RTL

الواجهة تتبدل تلقائياً بين LTR/RTL حسب لغة الرسالة، ولوحة القائمة والأزرار بالعربية.

## خطوات التنفيذ

1. تفعيل Lovable Cloud + تفعيل Google Auth
2. إنشاء migration لجداول conversations و messages مع RLS و GRANTs
3. صفحة الهبوط + تسجيل الدخول بجوجل
4. صفحة قائمة المحادثات (إنشاء/عرض/حذف)
5. صفحة الدردشة: عرض الرسائل + Hook للـ Web Speech API (STT + TTS)
6. Server function `chat` مع Gemini + structured output + system prompt يشمل معلومات المطور
7. بطاقة التصحيح + Animations + typing indicator + موجة تسجيل
8. PWA manifest + service worker + أيقونة (قابل للتثبيت على الشاشة الرئيسية)
9. Meta tags لكل route
10. اختبار كامل: تسجيل صوتي، رد بالعربية مع تشجيع، رد بالإنجليزية مع تصحيح، سؤال عن المطور
