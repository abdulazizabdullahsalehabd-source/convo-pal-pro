
## المشاكل التي سنعالجها
1. النطق العربي ضعيف وينطق الإيموجي والرموز.
2. النطق الإنجليزي أحياناً غير دقيق.
3. التعرف الصوتي عبر متصفح الهاتف غير دقيق، ويستخدم "الضغط المطوّل" بدلاً من التبديل بضغطة.
4. الذكاء الاصطناعي أحياناً يجيب بلغة مختلفة عن السؤال، أو يجيب بجواب لا علاقة له بالسؤال.

## الحل

### 1) التعرف الصوتي (STT) — دقيق ومجاني عبر Lovable AI
- استبدال Web Speech API بالخادم: `openai/gpt-4o-mini-transcribe` عبر Lovable AI Gateway (مجاني ضمن الرصيد الشهري، أدق بكثير من متصفح الجوال ويفهم العربية والإنجليزية تلقائياً).
- إنشاء server route: `src/routes/api/transcribe.ts` يستقبل ملف صوت ويعيد النص (multipart).
- إعادة كتابة `src/hooks/use-speech.ts` لاستخدام `MediaRecorder` (تسجيل WAV/webm) ثم رفعه إلى `/api/transcribe`.

### 2) زر المايك — ضغطة واحدة تبديلية
- في `src/routes/_authenticated/conversations.$id.tsx`: تغيير سلوك `MicButton` من `onMouseDown/Up` إلى `onClick` واحد يبدأ التسجيل، وضغطة ثانية توقفه وترسل الصوت تلقائياً للـ STT ثم للـ AI.
- إظهار مؤقت زمني وموجة بسيطة أثناء التسجيل.
- إزالة زر تبديل لغة التسجيل (EN/AR) — الاكتشاف تلقائي على الخادم.

### 3) النطق (TTS) — عربي فصيح ومجاني
- استبدال `speechSynthesis` بـ Lovable AI TTS: `google/gemini-2.5-flash-tts` (نطق عربي طبيعي جداً) للعربية، و`openai/gpt-4o-mini-tts` (voice: `alloy`) للإنجليزية.
- إنشاء server route: `src/routes/api/speak.ts` يمرّر SSE من الـ Gateway إلى المتصفح.
- في `use-speech.ts`: دالة `speak(text, lang)` جديدة تنظّف النص أولاً (تحذف الإيموجي والرموز غير النصية) ثم تشغّله عبر Web Audio API من الـ PCM stream.
- دالة التنظيف تستخدم regex لحذف رموز Unicode Emoji وعلامات الزخرفة قبل الإرسال للـ TTS.

### 4) ذكاء الردود — نموذج أقوى وقواعد أشد
- ترقية النموذج في `src/lib/chat.functions.ts` من `google/gemini-3.1-flash-lite` إلى `google/gemini-3.6-flash` (أذكى، مجاني ضمن نفس الفئة، فهم عربي وإنجليزي أفضل بكثير).
- تشديد system prompt:
  - قاعدة صريحة: "أجب دائماً على السؤال الفعلي المطروح — لا تنحرف عن الموضوع".
  - قاعدة صريحة: "اللغة المستخدمة في الرد يجب أن تطابق لغة آخر رسالة من المستخدم مطابقة تامة".
  - أمثلة قصيرة داخل الـ prompt (few-shot) لسؤال "How old are you?" و"كم عمرك؟" لضمان الالتزام.
  - قاعدة نحوية عربية: "الرد العربي يجب أن يكون فصيحاً سليم النحو والإعراب".

## الملفات المتأثرة
- `src/hooks/use-speech.ts` (إعادة كتابة كاملة)
- `src/routes/api/transcribe.ts` (جديد)
- `src/routes/api/speak.ts` (جديد)
- `src/routes/_authenticated/conversations.$id.tsx` (زر المايك + إزالة مبدّل اللغة)
- `src/lib/chat.functions.ts` (ترقية النموذج + تحسين الـ prompt)

## ملاحظات تقنية
- كل شيء يبقى مجانياً عبر Lovable AI Gateway (رصيد شهري تلقائي).
- المفتاح `LOVABLE_API_KEY` موجود مسبقاً.
- لا تغييرات على قاعدة البيانات ولا على المصادقة.
